# m-reader 部署说明（预留）

> 本文档用于记录 m-reader 应用的 Docker 化部署流程，详细步骤将随后补充。

在正式文档发布前，可参考仓库根目录提供的 `docker-compose.example.yml` 获取环境变量和端口映射示例，尤其适用于宝塔 Docker 场景。请确认：

- `APP_PORT` 默认为 `1314`，可以在运行时覆盖；
- 数据库环境变量 `DB_HOST`、`DB_PORT`、`DB_NAME`、`DB_USER`、`DB_PASSWORD` 采用占位值 `20251022`，请根据实际数据库配置进行修改；
- 在容器启动脚本中会预留数据库迁移步骤（当前为占位命令）。

待后续补充完成后，本文件将提供更完整的部署与运维指引。
